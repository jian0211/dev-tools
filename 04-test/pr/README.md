# pr

PR 본문을 쓰는 절차다. 리뷰가 아니다. 변경의 핵심을 그림이나 diff로 보여주고, 되기 전과 후를 붙이고, 되돌릴 수 있는지와 영향 범위를 적는다.

PR 本文を書く手順。レビューではない。変更の核心を図や diff で見せ、前と後を添え、戻せるかと影響範囲を書く。

호출하는 절차는 [SKILL.md](SKILL.md)에 참고한 원문 그대로 둔다. 이 파일은 설명만 담는다.

呼び出す手順は [SKILL.md](SKILL.md) に、参考にした原文のまま置く。このファイルは説明だけを置く。
