# karpathy-guidelines

LLM이 코드를 짤 때 자주 하는 실수를 줄이는 행동 지침이다. 구현, 리뷰, 리팩터를 요청받으면 가정을 숨기지 않고, 요청하지 않은 기능을 넣지 않고, 고친 줄만 건드리고, 확인할 수 있는 완료 조건을 둔다. 신중함 쪽이라 자잘한 수정에는 굳이 켜지 않는다.

LLM がコードを書くときの失敗を減らす行動指針。実装、レビュー、リファクタを頼まれたら、仮定を隠さず、頼まれていない機能を足さず、直した行だけ触れ、確認できる完了条件を置く。慎重さに寄るので、細かい修正では無理に使わない。

호출하는 절차는 [SKILL.md](SKILL.md)에 참고한 원문 그대로 둔다. 이 파일은 설명만 담는다.

呼び出す手順は [SKILL.md](SKILL.md) に、参考にした原文のまま置く。このファイルは説明だけを置く。
