# attention-span

에이전트의 코딩 절차가 아니라, 답을 말하는 방식을 바꾸는 스타일이다. 답을 먼저 말하고 짧게 끊는다. 원문은 가져오지 않았다.

エージェントのコーディング手順ではなく、答えの話し方を変えるスタイル。答えを先に言い、短く区切る。原文は持ち込んでいない。
